САЙТ «ВИШИВКА»
================

Як відкрити сайт:
1. Розпакуйте архів у будь-яку папку.
2. Відкрийте файл index.html у браузері.
3. Переходьте між сторінками через спільне меню навігації.

Структура:
- index.html     — головна сторінка
- history.html   — історія української вишивки
- types.html     — види та техніки
- gallery.html   — галерея
- style.css      — спільне оформлення всіх сторінок
- images/        — зображення сайту

Усі сторінки пов'язані між собою посиланнями. CSS винесено в окремий файл.
